# Exercício módulo 8 — Laços de repetição

Solicita um nome e um número positivo. Exibe contagens crescente e decrescente e repete o nome conforme seu tamanho.

## Conceitos praticados

Laços for e while, validação de entrada e métodos.

## Como executar

1. Abra a pasta do projeto no IntelliJ IDEA.
2. Configure um JDK 17 ou superior.
3. Execute o método main da classe exercicioModuloOito.
